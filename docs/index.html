Abstract

Measuring, Not Assuming, Quantum Communication Efficiency

Workshop calls for quantum machine learning in 6G routinely ask for high-quality datasets, reproducible testbeds, and industry-oriented, trustworthy solutions. Yet most reported results are single-point accuracy claims for a proposed algorithm, not a controlled characterization of when a variational quantum circuit (VQC) is actually worth deploying. FedQSense is a fully reproducible testbed that answers this directly: a three-tier device-to-fog-to-cloud hierarchical FedAvg protocol, structurally analogous to the layered architectures envisioned for 6G space-air-ground integrated networks (SAGIN), applied to a real early-warning task predicting next-day heavy-pollution events from the 12-station Beijing Multi-Site Air-Quality dataset, where each monitoring station is a natural, non-IID federated client.

We compare VQC clients against parameter-matched and full-feature classical baselines across qubit budgets of 4, 6, and 8, five random seeds each, reporting communication payload, accuracy, and a barren-plateau gradient-variance diagnostic side by side.
The honest finding: at shallow depth, VQCs transmit as few parameters as the matched classical baseline but trail it by 0.19–0.24 ROC-AUC: compactness alone does not win. Deeper circuits close much of the gap (AUC 0.79 at depth 4, still under half the parameters of the full-feature classical reference) but at a measured trainability cost consistent with the barren-plateau phenomenon. We report this trade-off honestly rather than cherry-picking a win.
System Design

Three-Tier Hierarchical FedAvg

Twelve real air-quality monitoring stations act as edge clients. Fog groupings are derived deterministically from the data itself: each station's mean pollutant profile is ranked along its first principal component and cut into four equal buckets, with no external geographic metadata assumed.

Tier 3: City / Cloud

Global Model: sample-weighted average of 4 fog models

Broadcasts the updated global model back down to every edge for the next round.

Code & Experimental Artifacts

All source code, dataset processing scripts, raw per-round results, and figures are publicly available. The manuscript itself is not included (IEEE copyright once submitted).

src/data/loader.py

Beijing dataset loader, daily aggregation, PCA, data-driven fog clustering.

src/vqc/circuit.py

Natively-batched PennyLane VQC client model.

src/classical/mlp.py

Matched-input and full-feature classical baselines.

src/tiers/hierarchical_fedavg.py

3-tier hierarchical FedAvg training loop.

src/integrity/hashchain.py

SHA-256 update-integrity hash chain (not a blockchain).

experiments/

Main sweep, depth ablation, barren-plateau diagnostic, integrity overhead.

results/

Every raw CSV/JSON number reported in the paper.

tests/

pytest suite: data pipeline, models, FedAvg, hash chain.
